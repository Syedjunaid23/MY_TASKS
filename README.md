# 100-Day Study Tracker 

This version is a static frontend designed for GitHub Pages. Progress is stored in Supabase, so the same account can use the tracker from multiple devices.

## Deployment
1. Put the contents of `public/` in a GitHub repository (or keep the whole project and publish the `public` folder through an appropriate Pages workflow).
2. Enable GitHub Pages.
3. Open the Pages URL and sign in with the Supabase Auth account.

The browser only contains the Supabase project URL and publishable key. Never put a Supabase secret/service-role key in this repository.
